# README
[![DOI](https://shields.io)](https://doi.org/10.5281%2Fzenodo.22903641)

Python code scripts and materials used to reproduce analysis figures in:

## Phoa et al. 2026 - Structural Limitations of Analog Based Statistical Downscaling on Precipitation Extremes

Corresponding author : Theresia B. Phoa (theresia.phoa@earth.miami.edu) or tbp32@miami.edu

## Contents:
1. Code :
   - `environment.yml`: python package required to run the analysis
   - `python-notebook` : folder containing individual python notebook to reproduce the figures presented on the paper
2. Data :
   - `FL-COOP-WBAN.csv` : List of NWS COOP Station coordinates within South Florida domain
